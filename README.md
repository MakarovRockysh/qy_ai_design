# 清明上河园 AI 场景化 HTML 原型

本目录是一套独立的新原型，用于按业务场景展示完整流程。它不会覆盖以下既有内容：

- 蓝湖原型；
- `http://127.0.0.1:5173/` 高保真交互原型；
- `../qingyuan-ai-html/` 可编辑原型和投诉工单原型。

## 当前内容

- 29 个业务场景；
- 265 个独立原型页面；
- 36 个异常或业务分支页面；
- 45 个结果页面；
- 游客端手机页面与投诉工单后台；
- 场景目录，以及按“主流程、异常/分支、结果状态”分组的逐页总览。
- S03 保留为 AI 会话交互基准；S06—S14 已打通统一规划入口、攻略生成、自然语言调整、路线地图、待购办理、实名校验、组合支付、订单凭证、状态回写和行程全生命周期；S25—S29 补齐 AI 票务顾问、三类典型游客场景和 AI 投诉助手。
- S09 每日攻略支持拖动行程项调整时间，便于演示游客在已生成攻略上进行轻量编排。

完整场景清单见 [SCENARIO_CATALOG.md](./SCENARIO_CATALOG.md)，逐场景页面顺序见 [PROCESS_INDEX.md](./PROCESS_INDEX.md)。
本轮运行与交互检查结果见 [VALIDATION.md](./VALIDATION.md)。

## 打开方式

可以直接双击 `index.html`。也可以在当前目录启动静态文件服务后访问：

```text
http://127.0.0.1:8003/
```

## 使用方式

1. 在左侧选择业务场景。
2. 在同一画布查看该场景页面；主流程、异常/分支和结果状态均默认展开，可按需收起。
3. 点击任意手机或后台原型可打开交互预览。
4. 在交互预览中点击页面按钮，可在同一设备窗口连续进入下一业务状态；按 `Esc` 或右上角关闭。
5. 投诉场景中的受理、退回补充、驳回、转派和完结均通过弹窗演示。

## 文件说明

- `index.html`：原型外壳；
- `styles.css`：场景目录、手机页面、后台页面和弹窗样式；
- `scenarios.js`：29 个场景、业务流程、页面内容和页面跳转；
- `app.js`：目录、场景总览、搜索、页面定位和弹窗交互；
- `SCENARIO_CATALOG.md`：场景范围、角色、起点、结果和页面范围；
- `PROCESS_INDEX.md`：29 个场景的主流程、异常分支和页面顺序；
- `VALIDATION.md`：结构、运行和核心业务流程验收记录；
- `assets/`：页面使用的园区地图、首页鸟瞰图和宋韵场景 WebP 原型素材；原 PNG 仅保留为源稿。

## 交互说明

- 页面操作只模拟前端状态，不连接真实接口。
- 浏览器刷新后仍可从 URL 中恢复当前场景和页面。
- 所有页面均可从场景流程节点直接定位；总览中的原型按钮会打开交互预览，并在同一设备窗口演示后续状态。
- 首页金刚区和底部导航可直接进入对应业务；表单、筛选、卡片、人数、出行人、座位、上传、评分和后台查询均可点击或编辑。
